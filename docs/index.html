03 — Approach

        
From telemetry to action.

        

          Effective security operations start with trustworthy log collection, useful detection
          logic, and a clear path from an alert to an investigation. My experience covers that
          workflow across QRadar, endpoint tooling, and response automation.
        


        

          Log Sources
          →
          SIEM Correlation
          →
          Detection Rules
          →
          Incident Triage
          →
          Response
        


        

          

            Collect
            
Onboard and normalize log sources so analysts can trust the evidence behind each alert.

          

          

            Detect
            
Write and tune QRadar rules and reports with AQL and Regex, aligned to MITRE ATT&CK.

          

          

            Respond
            
Investigate phishing, DDoS, and malware activity with endpoint and response tooling.
